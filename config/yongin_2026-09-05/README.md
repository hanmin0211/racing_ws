## ★ 주차 구간이 빠져 있다 (의도된 것)

1차 기록에 **되꺾임(cusp) 2개**가 있었다:

```
s=314.0m  (18.97, -44.39)  헤딩 -113.7° → +41.8°   (155° 반전)
s=326.0m  (27.84, -42.01)  헤딩  -26.1° → +153.8°  (180° 반전)
```

전진 주차 후 후진 주차를 하는 구간이라 **걸어서 들어갔다 나온 자리**다.
경기규정 항목 6·8 도 "후진으로 차고에 진입하여 뒷바퀴가 확인선을 접촉하고
전진으로 진입확인선을 통과" 라고 되어 있어 **웨이포인트로 표현할 수 없다**.

`pure_pursuit` 은 전진 전용이라 경로가 차 뒤로 이어지면 정지한다
(`local_pure_pursuit_node.py`: `lookahead가 차량 뒤/너무 가까움`).

→ 이 구간은 `parking_node` 가 `parking_pose_N.yaml` 을 보고 **그 자리에서** 궤적을
   만든다. 경로 파일에서는 도려낸다 (`tools/split_path.py`).
